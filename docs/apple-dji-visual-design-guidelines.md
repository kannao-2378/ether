# Apple × DJI 视觉设计规范

> 版本：1.2
> 日期：2026-09-03
> 适用范围：Hub、作品集入口页，以及后续新建的案例入口页。
> 参考：[Apple 首页](https://www.apple.com/) · [DJI 首页](https://www.dji.com/cn)

## 1. 设计原则

这套规范提取 Apple 的信息秩序、留白和克制交互，以及 DJI 的全幅视觉、产品聚焦和模块化入口。它用于建立统一体验，不复刻任一品牌的具体页面。

1. **一次只讲一件事**：一个首屏只保留一个主标题、一条说明和一组主要操作。
2. **视觉先于解释**：展示页以大幅媒体承载情绪，正文只负责说明方向。
3. **入口保持轻量**：总入口使用小卡片；大画面只用于具体内容模块。
4. **层级由比例建立**：依赖字号、留白、明暗和位置，不依赖复杂装饰。
5. **界面最终静止**：动画结束后所有内容保持稳定，不循环漂浮或闪烁。

## 2. 页面骨架

### 2.1 导航

- 桌面端高度：`48px`。
- 移动端高度：`48px`。
- 内容最大宽度：`1024–1240px`。
- 主导航使用单行小字号，最多保留 5 个信息点。
- 深色首屏使用半透明深色导航；浅色首屏使用半透明白色导航。
- 导航属于工具层，状态反馈控制在 `180–230ms`。

### 2.2 首屏

- 目标高度：`calc(100svh - 48px)`，最低不小于 `620px`。
- 主视觉占首屏面积约 `60–75%`。
- 文案采用居中或左下对齐，不同时使用多个焦点。
- 主标题最多两行；副标题建议不超过 36 个汉字。
- 主要操作不超过 2 个，默认使用文字链接或小型圆角按钮。

### 2.3 内容章节

- 大章节上下留白：桌面端 `112–160px`，移动端 `72–96px`。
- 相邻模块间距：`12–20px`。
- 所有内容模块统一使用 `28px` 圆角；胶囊按钮保持 `999px`。
- 页面按“深色沉浸 → 浅色解释 → 浅色索引 → 深色收束”形成节奏。

## 3. 栅格系统

- 页面外边距：桌面端 `32px`，平板 `20px`，手机 `12–20px`。
- 最大内容宽度：`1240px`。
- 展示模块：12 栏逻辑，可使用 `7:5`、`8:4` 或等分布局。
- 品牌案例：桌面端 4 列，平板 2 列，手机 1–2 列。
- 分类入口：桌面端 5 列，平板 3 列，手机 2 列。
- 同组卡片尺寸一致，避免无意义的随机 Bento 比例。

## 4. 字体层级

使用 Apple 系统字体栈：`-apple-system`、`BlinkMacSystemFont`、`SF Pro Display`、`SF Pro Text`、`PingFang SC`、`Helvetica Neue`。Apple 设备直接调用 SF Pro 与苹方；其它系统使用本机最接近的系统字体，不加载来源不明的字体文件。

| 层级 | 桌面端 | 移动端 | 建议字重 | 用途 |
|---|---:|---:|---:|---|
| Display | `56–96px` | `52–72px` | `600` | 首屏标题 |
| Section | `42–68px` | `38–52px` | `600` | 章节标题 |
| Group | `32–52px` | `28–40px` | `600` | 案例分类标题 |
| Card title | `22–32px` | `22–28px` | `600` | 卡片标题 |
| Subtitle | `17–21px` | `17px` | `400` | 副标题 |
| Body | `16px` | `16px` | `400` | 正文 |
| Caption | `14px` | `14px` | `400–500` | 卡片说明与辅助信息 |
| Label | `12px` | `12px` | `600` | 索引与眉题 |

- 大标题字距：`-0.04em` 至 `-0.06em`。
- 标题行高：`0.98–1.08`；副标题行高：`1.5`；正文行高：`1.625`。
- 英文眉题使用 `0.12em` 字距。
- 页面仅使用 `400 / 500 / 600` 三档字重，避免相近字重造成层级混乱。

## 4.1 间距系统

所有页面只使用统一的 4px 基础节奏：

| Token | 数值 | 主要用途 |
|---|---:|---|
| `space-1` | `4px` | 极小文字间距 |
| `space-2` | `8px` | 标签与标题、小组件间距 |
| `space-3` | `12px` | 紧凑内容间距 |
| `space-4` | `16px` | 标准元素间距 |
| `space-6` | `24px` | 卡片内间距、标题与正文 |
| `space-8` | `32px` | 大卡片内边距 |
| `space-12` | `48px` | 内容组间距 |
| `space-16` | `64px` | 章节标题与内容 |
| `space-24` | `96px` | 案例分类之间 |
| `space-32` | `128px` | 大章节留白 |
| `space-40` | `160px` | 宽屏最大章节留白 |

- 桌面章节上下留白采用 `112–160px` 的响应式范围。
- 手机章节上下留白采用 `72–96px` 的响应式范围。
- 卡片栅格间距桌面为 `16px`，手机为 `12px`。
- 标题到副标题默认 `16px`，章节标题到内容默认 `64px`。

## 5. 色彩与材质

| Token | 色值 | 用途 |
|---|---|---|
| `cosmic-orange` | `#f77314` | iPhone 17 Pro 宇宙橙；素材占位与重点 |
| `deep-blue` | `#2b3145` | iPhone 17 Pro 深蓝；深色卡片与次级模块 |
| `silver` | `#f5f5f5` | iPhone 17 Pro 银色；浅色章节背景 |
| `silver-ui` | `#f5f5f7` | Apple 浅灰；页面与索引背景 |
| `black` | `#000000` | 沉浸首屏、联系方式与案例空状态页 |
| `dark-surface` | `#121214` | 深色弹层与抬升表面 |
| `text-dark` | `#1d1d1f` | 浅色背景主文字 |
| `text-light` | `#f5f5f7` | 深色背景主文字 |
| `text-secondary` | `#6e6e73` | 浅色背景副标题与正文 |
| `text-tertiary` | `#86868b` | 深色背景辅助信息与次级元数据 |
| `link-blue` | `#2997ff` | 必要的文字链接和系统状态 |
| `hairline` | `rgba(0,0,0,.12)` / `rgba(255,255,255,.14)` | 分隔线与结构边界 |

- 大面积区域只使用黑色、银色和浅灰；深蓝用于少量深色模块。
- 宇宙橙只用于素材占位、焦点和非常少量的状态提示，不用作大段正文背景。
- 深蓝卡片使用 `#f5f5f7` 主文字，橙色占位使用 `#1d1d1f` 文字。
- 不使用渐变光晕、拟物玻璃堆叠或彩色投影作为主要设计语言。
- 阴影只用于浅色卡片分层，透明度保持在 `4–10%`。
- 圆角模块内部禁止添加装饰性描边或重复内框。

## 6. 媒体占位规范

- 未接入真实素材前，一律使用纯橙色矩形。
- 占位框保留编号、用途与推荐比例，例如 `IMAGE / 01 · 16:9`。
- 常用比例：首屏 `16:9`；海报 `4:5`；人物 `3:4`；案例卡 `4:3`。
- 占位框内部不制作假图片、插画或装饰性场景。
- 接入真实素材后直接替换背景或 `<img>`，不得改变外框比例和文字布局。

## 7. 卡片与入口

- Hub 入口卡高度：`218–260px`，同组等尺寸。
- 案例卡图片区域占卡片高度约 `55–65%`。
- 整张卡片可点击，文本链接不与整卡点击冲突。
- Hover 仅允许 `scale(1.01–1.02)`，持续 `300ms`。
- 箭头可移动 `2–4px`；不叠加旋转、发光或大幅阴影变化。

## 8. 动效

具体实现以 `docs/apple-interaction-motion-guidelines.md` 为准：

- 内容进入：`opacity 900ms + translateY(30px) 700ms`。
- 同组内容错峰：展示模块 `150ms`；密集入口 `80ms`。
- 导航与颜色反馈：`180–250ms`。
- 卡片 Hover：`300ms cubic-bezier(0, 0, .5, 1)`。
- 禁止循环动效、指针跟随光晕、无意义旋转和装饰性漂浮。
- `prefers-reduced-motion: reduce` 下取消位移和过渡。

## 9. 作品集四屏应用

1. **海报**：深色首屏 + 海报占位画廊；内容直接在本页展示，不设置详情入口。
2. **个人介绍**：暖白背景 + 人物占位与文字双栏；内容直接在本页展示。
3. **作品集合集**：浅灰背景，直接链接九个详情页：品牌案例 2×2、素材案例 3 列、其它案例 2 列，不设置中间目录页。
4. **联系方式**：深色收束 + 居中标题 + 小型橙色联系信息卡，不设置详情入口。

移动端不强制每章物理上占满一屏；应优先保证内容完整、顺序清晰和触控区域充足。
