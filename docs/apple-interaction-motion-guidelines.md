# Apple 风格交互与动效基准

> 参考页面：<https://www.apple.com/iphone-17-pro/>  
> 检查日期：2026-07-25  
> 实测环境：桌面端，1280 × 720 视口  
> 用途：本项目后续所有动效、交互设计与代码评审的默认基准。

## 1. 核心结论

Apple 的动效不是“给每个元素加特效”，而是用少量、重复且可预测的运动语言组织阅读顺序：

1. 内容进入以 `opacity + translateY` 为主。
2. 同组内容使用短间隔错峰，而不是同时飞入。
3. 卡片反馈只做轻微缩放，不使用指针跟随光晕。
4. 大型视觉变化优先使用视频、首尾静态帧或滚动区间驱动。
5. 动画结束后界面回到稳定静止状态，不持续漂浮、闪烁或循环。
6. 动画与加载解耦：媒体提前加载，接近视口时才播放。
7. 为减少动态效果、无 JavaScript 和加载失败准备静态降级。

本项目后续禁止仅为了“看起来炫”而添加光晕跟随、持续浮动、无意义旋转、弹跳或过度景深。

## 2. 实测动效参数

### 2.1 分组滚动进入

Apple 页面大量使用 `StaggeredFadeIn`：

| 参数 | 实测值 |
|---|---:|
| 单项错峰间隔 | `150ms` |
| 透明度持续时间 | `900ms` |
| 垂直移动距离 | `30px` |
| 垂直移动持续时间 | `700ms` |

推荐实现：

```css
.item {
  opacity: 0;
  transform: translateY(30px);
}

.section.is-visible .item {
  opacity: 1;
  transform: translateY(0);
  transition:
    opacity 900ms ease,
    transform 700ms cubic-bezier(0.16, 1, 0.3, 1);
}

.item:nth-child(2) { transition-delay: 150ms; }
.item:nth-child(3) { transition-delay: 300ms; }
```

注意：`cubic-bezier(0.16, 1, 0.3, 1)` 是本项目用于接近 Apple 观感的实现曲线，不是从该页面声明中直接读取的统一曲线。Apple 原站的进入动画由组件脚本协调。

#### 不同文字如何进入

Apple 并不是给标题、正文、按钮分别设计完全不同的花式动画，而是复用同一套
`StaggeredFadeIn`，通过顺序、延迟、距离和是否位移建立层级：

| 文字类型 | 初始状态 | 进入方式 | 推荐顺序 |
|---|---|---|---:|
| 章节眉题、小标签 | `opacity: 0`，可不位移 | 快速淡入 | 1 |
| 主标题 | `opacity: 0; translateY(30px)` | `900ms` 淡入，`700ms` 上移归位 | 1–2 |
| 副标题、说明文字 | `opacity: 0; translateY(30px)` | 与主标题相同，延迟 `150ms` | 2–3 |
| 数据、强调数字 | `opacity: 0; translateY(30px)` | 按列或按组逐项错峰 | 3 |
| 按钮、文字链接 | `opacity: 0`，短距离位移或无位移 | 内容稳定后出现，再延迟 `150ms` | 最后 |
| 导航、索引文字 | `opacity: 0; translateY(-4px)` | `320ms` 快速进入 | 独立 |

执行规则：

1. 同一文字块内部通常整体进入，不逐字、逐行飞入。
2. 主标题和正文的延迟差默认是 `150ms`。
3. 工具型文字比展示型标题快；导航和索引不使用 `700–900ms` 的慢动画。
4. 小标签允许只改变透明度，通过
   `data-staggered-item-no-translate` 一类逻辑取消位移。
5. 文字不使用旋转、弹跳、指针跟随或持续漂浮。
6. 同一屏的阅读顺序应为：

```text
眉题/主标题 → 副标题/正文 → 数据或媒体 → 操作按钮
```

推荐代码结构：

```css
.motion-eyebrow {
  opacity: 0;
  transition: opacity 500ms ease;
}

.motion-title,
.motion-copy {
  opacity: 0;
  transform: translateY(30px);
  transition:
    opacity 900ms ease,
    transform 700ms cubic-bezier(0.16, 1, 0.3, 1);
}

.is-visible .motion-title   { transition-delay: 0ms; }
.is-visible .motion-copy    { transition-delay: 150ms; }
.is-visible .motion-action  { transition-delay: 300ms; }
```

#### 不同卡片如何进入

需要区分“卡片进入页面”“卡片 hover”和“画廊切换”，三者不是同一个动画：

| 卡片类型 | 进入方式 | 时间与延迟 | 进入后状态 |
|---|---|---|---|
| 单张大卡片 | 整卡 `opacity + translateY(30px)` | 淡入 `900ms`，位移 `700ms` | 完全静止 |
| 同行卡片组 | 每张整卡依次进入 | 相邻卡片错峰 `150ms` | 完全静止 |
| 密集小卡片/索引卡 | 小距离、短延迟进入 | `20–80ms` 逐项错峰 | 完全静止 |
| 横向画廊卡片 | 当前卡先稳定显示，控制器随后出现 | 卡片切换约 `1s`，控制器延迟 `740–940ms` | 支持滚动与暂停 |
| 视频卡片 | 开始帧先显示，进入播放区后播放 | 帧切换 `200ms` | 视频结束后显示结束帧 |

卡片组的顺序：

```text
第一张：0ms
第二张：150ms
第三张：300ms
第四张：450ms
```

如果卡片超过四张，应考虑分组或缩短到 `80ms`，避免最后一张等待过久。

卡片进入时：

- 整张卡片作为一个对象移动。
- 卡片内部图片、标题和说明默认不再各自飞入。
- 如果卡片内部确实需要分层，必须先让卡片稳定，再显示内部控制器或状态。
- 卡片进入完成后停止运动，不持续上下浮动。

卡片 hover 是另一套快速反馈：

```css
transition: transform 300ms cubic-bezier(0, 0, 0.5, 1);
```

hover 只允许轻微缩放；不复用卡片进入时的 `700–900ms` 慢动画。

### 2.2 卡片悬浮

Apple 的通用卡片规则：

```css
transition: transform 300ms cubic-bezier(0, 0, 0.5, 1);
```

具体缩放值由各组件变量控制，并非所有卡片使用同一个比例。因此本项目默认：

- 桌面端缩放不超过 `1.02`。
- 不同时叠加大幅上移、旋转和阴影扩张。
- 触摸设备不使用 hover 特效。
- 禁止指针跟随光晕。

### 2.3 视频首尾帧

首屏视频实测：

| 项目 | 实测值 |
|---|---:|
| 视频时长 | `3s` |
| 播放方式 | 静音、行内播放、单次播放 |
| 循环 | 否 |
| 加载超时 | `3000ms` |
| 结束帧淡入 | `400ms ease-out` |

结构不是单独一个 MP4，而是：

```text
开始 JPG → MP4/WebM 视频 → 结束 JPG
```

播放结束后显示结束帧并卸载视频。加载失败、减少动态效果或脚本不可用时显示静态图片。

### 2.4 普通媒体与画廊切换

| 参数 | 实测值 |
|---|---:|
| 普通帧切换 | `200ms` |
| Media Card Gallery 共享切换 | `1s` |
| 自动播放动画 | `5s` |
| 单张停留周期 | `6.15s` |
| 状态重置 | `200ms` |

画廊控制器：

| 状态 | 延迟 | 持续时间 |
|---|---:|---:|
| 圆点导航淡入 | `740ms` | `100ms` |
| 播放按钮淡入 | `940ms` | `100ms` |
| 播放按钮缩放 | `940ms` | `200ms ease-out` |
| 控件背景变化 | — | `250ms` |

原则：内容先稳定进入，再显示控制器；控制器不能抢在内容之前出现。

#### 焦段选择图库（200 mm / 24 mm / Macro）

2026-07-26 对相机焦段选择屏补充实测：

| 项目 | 实测值 |
|---|---:|
| 新图片叠层淡入 | 约 `160ms` |
| 旧图片处理 | 淡入期间保持在下层，完成后再隐藏 |
| 未选文字透明度 | `0.8` |
| 文字状态反馈 | 未选 `120ms ease-out`；选中 `160ms ease-in` |
| 白色滑块移动 | `left + width`，`320ms ease-out` |

该组件切换图片时不做缩放、上下位移或模糊。新图直接在旧图上方快速淡入，
外框尺寸保持不变；标签只改变填充与文字颜色。项目中的同类选项卡图库默认沿用：

```text
内容叠层淡入 160–200ms
文字反馈 120–160ms
选中滑块以独立元素连续移动 320ms ease-out
```

滑块不能通过给目标按钮直接添加白色背景来“瞬间换选中态”。应保留一个独立的
绝对定位指示器，根据目标按钮的 `offsetLeft` 和 `offsetWidth` 同时过渡
`left` 与 `width`。首次初始化和窗口尺寸变化时直接定位，不播放滑移动画；
只有用户切换选项时才播放。

### 2.5 导航显示

局部导航从顶部进入：

```css
transition: transform 230ms;
```

导航属于快速功能反馈，不应使用接近 1 秒的展示型动画。

### 2.6 索引列表进入

| 参数 | 实测值 |
|---|---:|
| 动画持续时间 | `320ms` |
| 组级延迟 | `80ms` |
| 短延迟 | `40ms` |
| 快速逐项延迟 | `20ms` |
| 初始位移 | `-4px` |
| 额外开始延迟 | `200ms` |

索引、导航和按钮等工具型元素应比海报与内容模块更快。

## 3. 滚动与媒体触发规则

Apple 不是等媒体完全进入视口后才加载：

### 普通章节视频

- 距离视口约 `100vh` 时开始加载。
- 元素顶部进入视口约 `65vh` 范围时开始播放。
- 播放完成后显示结束帧并卸载媒体。

### 产品查看器视频

- 距离锚点约 `150vh` 时加载。
- 距离锚点约 `100vh` 时进入播放区间。
- 使用更宽的前后区间，防止快速滚动时出现空白。

### 长滚动视频章节

- 最远提前约 `200vh` 加载。
- 进入约 `70vh` 播放范围后启动。
- 离开指定滚动容器时暂停或重置。

项目规则：

1. 视频至少提前 `100vh` 加载。
2. 不要让首个可见帧依赖网络即时返回。
3. 视频必须配置静态 poster 或结束帧。
4. 非循环内容默认只播放一次。
5. 离屏后不应继续占用不必要的解码资源。

## 4. 滚动驱动视觉

页面中的三图合拢等效果由滚动区间驱动，不使用固定秒数：

- 左右图片：`x + y` 从偏移位置回到 `0`。
- 中间图片：`scale + y` 回到最终状态。
- 文本：轻微 `y` 位移回到 `0`。
- 缓动函数：`easeInOutSin`。
- 平滑参数：`0.5`。
- 无增强模式时禁用。

适用场景：

- 产品拆解与合拢。
- 多张图片构成一张完整视觉。
- 长页面中的章节转场。

不适用场景：

- 普通按钮。
- 简单卡片。
- 导航菜单。
- 仅需要一次进入动画的文本。

## 5. 交互模式归纳

### 卡片

- hover 仅提供轻微尺寸反馈。
- 点击目标必须覆盖完整卡片。
- 切换过程保持卡片外框稳定，避免布局跳动。
- 触摸端依赖点击和横向滚动，不依赖 hover。

### 横向画廊

- 使用原生横向滚动。
- 使用 `scroll-snap` 对齐卡片。
- 隐藏视觉滚动条，但保留触摸、触控板和键盘能力。
- 当前项通过圆点或进度条明确反馈。
- 自动播放必须提供暂停按钮。

### 视频

- 静音视频可以自动播放。
- 有声音的视频必须由用户主动触发。
- 播放、暂停、重播状态需要可访问标签。
- 结束后保持稳定画面，禁止突然黑屏。

### 选择器与按钮

- 颜色和背景反馈通常在 `100–250ms` 完成。
- 不使用夸张弹簧。
- 激活状态优先通过颜色、填充和图标变化表达。

## 6. 项目动效时间分级

后续实现优先使用以下分级：

| 类型 | 推荐持续时间 | 用途 |
|---|---:|---|
| 即时反馈 | `100–200ms` | 按钮、图标、颜色、焦点 |
| 功能转场 | `200–350ms` | 导航、下拉、卡片 hover |
| 内容进入 | `700–900ms` | 标题、图片、模块进入 |
| 章节转场 | `900–1200ms` | 大面板、组合视觉 |
| 视频 | 按素材时长 | 复杂产品或品牌叙事 |

同组错峰默认 `150ms`。只有密集列表可使用 `20–80ms`。

## 7. 本项目执行规则

以后修改交互或动效前必须：

1. 先阅读本文档。
2. 说明新增动画属于哪一类，以及使用的持续时间。
3. 优先复用已有运动语言，不创建新的随机特效。
4. 默认不使用指针跟随光晕。
5. 默认不使用持续循环动画。
6. 默认不同时叠加位移、缩放、旋转、模糊和阴影五类效果。
7. 同一元素最多使用两个主要动画属性，通常为：
   - `opacity + transform`
   - `opacity + filter`
8. 保证动画结束后元素回到稳定、清晰、可交互状态。
9. 添加 `prefers-reduced-motion` 降级。
10. 完成后在桌面端和移动端各验证一次。

## 8. 针对当前“03-能力”模块的建议

保留：

- 面板滚动进入。
- 标题先进入，角色说明延迟 `150ms`，卡片组再延迟 `150ms`。
- 三张卡片分别使用 `0 / 150 / 300ms` 错峰进入。
- 每张卡片内部作为整体显示，不再单独弹出标签。
- 卡片轻微缩放反馈。
- 下拉选择器 `200–250ms` 状态变化。
- 链接箭头短距离位移。

删除或避免：

- 指针跟随光晕。
- 雷达图无依据旋转。
- 大幅卡片上移。
- 点击后永久发光。
- 与内容无关的标签浮现。

建议参数：

```text
面板：opacity 900ms + translateY 30px / 700ms
卡片：每张延迟 150ms
hover：transform 300ms cubic-bezier(0, 0, 0.5, 1)
选择器：border/background 200–250ms
箭头：transform 200–300ms
```

## 9. 信息可信度说明

本文档中的数值分为两类：

- **实测值**：从 Apple 页面当前 DOM、CSS 自定义属性、媒体元数据和组件配置中读取。
- **项目建议值**：基于实测规律，为当前原生 HTML/CSS/JavaScript 项目整理的统一实现方案。

Apple 页面会更新。若参考页面结构或资源版本变化，应重新检查并更新本文档日期和参数。

## 10. DJI 风格全屏背景放大章节

参考页面：<https://www.dji.com/cn/mavic-4-pro?site=brandsite&from=homepage>  
实测区域：“云台 / 高能配置，用影像还原想象”  
检查日期：2026-07-25  
实测视口：1280 × 720

该区域不是视频，而是静态背景图片配合长滚动区和 `position: sticky` 实现：

| 项目 | 实测值 |
|---|---:|
| 滚动区高度 | `2250px`，约 `312.5vh` |
| 粘性舞台高度 | `100vh` |
| 图片初始尺寸 | `844 × 481px`，约视口的 `2/3` |
| 图片最终尺寸 | `1266 × 721.5px`，约为全屏 |
| 原站缩放 | `scale(1)` → `scale(1.5)` |
| 等效全屏缩放 | `scale(.6667)` → `scale(1)` |
| 变换原点 | `center bottom` |
| 图片透明度 | `0` → `1` |
| 文字初始位移 | `translateY(15px)` |
| 文字透明度 | `0` → `1` |
| 底部退场遮罩 | `30vh` 黑色渐变 |

执行顺序：

```text
章节接近视口 → 图片由 2/3 尺寸放大并淡入
→ 图片铺满视口并固定
→ 眉题与标题同步从下方 15px 淡入
→ 画面和文字保持稳定
→ 章节底部通过黑色渐变衔接下一段
```

实现要求：

1. 图片缩放和文字进入均由滚动进度驱动，不使用固定时长播放。
2. 使用 `requestAnimationFrame` 对滚动目标值做轻度平滑，停止滚动后必须收敛到目标状态。
3. 背景素材使用独立图片，设计稿文字必须作为 HTML 文本保留。
4. 桌面端使用完整长滚动区；移动端可缩短到约 `240vh`，但仍保持粘性全屏舞台。
5. `prefers-reduced-motion: reduce` 下取消滚动缩放，直接显示最终全屏画面和文字。
