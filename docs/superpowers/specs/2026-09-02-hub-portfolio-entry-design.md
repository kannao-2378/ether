# Hub 主入口页 + 作品集入口页 设计文档

日期：2026-09-02
状态：已与用户逐项确认

## 1. 背景与目标

用户是品牌视觉总监，现有老站（项目根目录）是一个交互较多的沉浸式作品集，以 qreate 案例为主。现需要：

1. 一个**主入口页（hub）**：作为个人域名下所有入口（作品集、blog、写作、App、社区等）的门面。
2. 一个**作品集入口页**：承载海报、个人介绍、作品集合集、联系方式四个入口。
3. 所有入口均为"点开进入另一个界面"的独立页面，不与老站共享运行时。

**约束**：老站现阶段不动；新页面不引入构建工具；视觉延续老站苹果风格；动效遵循 `docs/apple-interaction-motion-guidelines.md`。

## 2. 技术方案

纯静态多页面（方案 A，已确认）：

- 每个模块文件夹一个独立 `index.html`，页面间普通 `<a>` 链接跳转。

- 公共样式集中在 `hub/shared.css`，各页面以相对路径引用。

- 无构建、无加载器、无框架；老站文件零改动。

## 5. 页面设计

### 5.1 hub 主入口页（本期重点 1）

- 黑底 `#0f141d`，Apple 产品页式排版：居中大标题（姓名 + 品牌视觉总监定位）+ 一句副标题。

- 主视觉位一张**作品集大卡片**（宽约 2/3，配图或渐变占位），点击进入作品集入口页。

- 下方一排 4 张灰色"即将上线"小卡：Blog / 写作 / App / 社区。

### 5.2 作品集入口页（本期重点 2）

- 顶部"← 返回主页"链接。

- 大标题"作品集"+ 一句话定位（首屏 5 秒讲清"你是谁、做什么、什么水平"，沿用求职作品集定位原则）。

- 4 个入口卡片：**作品集合集**为主卡（视觉分量最大），海报、个人介绍、联系方式为次级卡。

- 每张卡 = 静态预览图/渐变 + 标题 + 一句描述，整卡可点。

### 5.3 模块骨架页（所有其余文件夹）

- 统一"建设中"占位模板：黑底 + 模块中文标题 + 返回上级链接。

- 保证整个导航树无死链；以后逐个模块填充内容。

## 6. 视觉与动效规范

**视觉**（沿用老站变量）：

| 变量   | 值                                               |
| ---- | ----------------------------------------------- |
| 页面背景 | `#0f141d`（html 为 `#000`）                        |
| 正文文字 | `#f5f5f7`                                       |
| 点缀色  | `#fe9349`（橙）                                    |
| 字体栈  | SF Pro / MiSans / PingFang SC / Microsoft YaHei |

**动效**（严格遵循动效基线文档）：

- 内容进入：`opacity 900ms ease` + `translateY(30px) 700ms cubic-bezier(0.16,1,0.3,1)`，卡片组错峰 `150ms`。

- 卡片 hover：`transform 300ms cubic-bezier(0,0,0.5,1)`，缩放 ≤ `1.02`；触摸设备无 hover 特效。

- 禁止：循环动效、光标跟随光晕、装饰性浮动、五类效果叠加。

- `prefers-reduced-motion: reduce` 降级为直接显示。

## 7. 老站迁移计划（新页面验收后执行）

**时机**：hub 页 + 作品集入口页建好并经用户验收后，单独一次提交执行。

**范围**（已确认"除 hub 和文档外全移"）：

- 移入 `hub/sites/portfolio-legacy/`：老站全部文件——`index.html`、`sections/`、`assets/`、`styles/`、`config/`、`section-loader.js`、`admin/`、`admin.html`、`netlify/`、`netlify.toml`、`deploy-oss.cjs`、`oss-fix-website.cjs`、`package.json`、`dev-server.mjs`、`README.md`、本地脚本等。

- 留在项目根：`hub/`、`AGENTS.md`、`docs/`、`.gitignore`（技术必需）。

**线上切换（无感方案）**：

1. 服务器 `git pull` 拉取迁移提交。
2. 同一时间窗口内修改 nginx：站点根目录指向 `hub/sites/portfolio-legacy/`，`sudo systemctl reload nginx`。
3. 效果：访客看到的 `kannao.top` URL、内容、外观完全不变，仅磁盘位置改变。
4. 若不同步改 nginx，根目录无 `index.html`，线上 404——**这是必须避免的事故**。

**后续（不在本期）**：新站稳定后，nginx 切换指向 `hub/`，老站退役或按计划整理进 `works/brand-cases/qreate/`。

## 9. 验收标准

1. `hub/index.html` 本地打开：标题、作品集大卡、4 张占位卡（点击弹"暂未开启"）正常。
2. 作品集入口页：4 个入口卡可点，返回链接正常。
3. 全部模块骨架页可从入口页到达，返回链接逐级正常，无死链。
4. 移动端与桌面端各检查一遍布局与动效降级。
5. 老站（项目根）文件零改动（`git status` 不出现老站文件变更）。
