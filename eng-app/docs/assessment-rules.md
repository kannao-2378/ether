# 反馈、保持与迁移的联合判断

用户依旧只选择认识/模糊/忘记。记录不会被新反馈覆盖，返回改选以最新反馈参与计算。

- 独立通过：最后拼写正确，提交前无错误、无提示，且反馈认识。
- 当天重复正确只算当天证据。延迟成功要求距上次练习至少24小时。
- 稳固初始门槛：至少3个独立成功自然日、至少2次延迟成功、其中一次间隔≥7天；最近10次独立通过率≥80%，最近一次独立通过。不是墨墨算法或科学保证，后续可校准。
- 后续模糊、忘记、错误或提示会让当前保持状态回到待巩固，历史成功不删除。
- 迁移按已登记结构与材料关系取证，同一材料重复不增加材料种类；至少2种材料才显示不同情境证据。没有关系登记的内容不推断迁移。
- 看过讲解不产生掌握证据。测试跳过不产生保持/迁移证据；测试数据不影响真实库。
- 普通答题仍由原间隔调度；未满足稳固门槛时，新计算的长期间隔最多7天。已发生的正确使用通过覆盖机制减少当天重复。
- 独立验证后的解锁资格继续与长期保持状态分开，不能因等级标签变化重复锁住已学课程。
