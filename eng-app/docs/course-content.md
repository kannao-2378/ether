# 基础课程与释义内容

已提供一条通用英语基础路线：6 个单元、66 个现有与新增学习条目。单元包含动作材料、愿望表达、活动喜好、决定与选择、动作与对象、日常动作。新学按课程内可用条目的顺序安排，跨天到期复习仍优先；已有学习记录与复习上限不重置。它是自编示范课，不是官方原版教材或 3000 条高频课程。

knowledge 保留稳定 ID、英文、中文提示、解释和原例句；knowledge_details 通过 knowledge_id 保存版本化的读音、音节、重音、词性、英文释义、结构、知识点、例句翻译、错误提示、词形、词源、延伸及来源。learning_courses / course_units / course_items 组织课程，不复制学习记录。内容迁移可重复执行，不改原答案与既有进度。

释义页和词典共用 KnowledgeContent。直接展示内容类型、适用词性、已补充的美式音标、发音按钮、音节重音、结构与核心用法、双语例句和适用错误提示。词形、词源、延伸、来源可展开；不适用或尚无可靠信息的字段不显示空栏目。句子按句型结构展示，不给整句强行标词性、词根。首批单词有明确读音信息，其他表达保留本机整段朗读；部分句型显示核心动词读音，不冒充整句音标。

教学说明和例句为自编；want/enjoy 等动词接法参考 British Council，首批单词的读音与用法附 Oxford 词典入口。词源仅作为记忆线索，与构词规则区分；不承诺每个词有可拆解词根。其余领域课程和完整多义项内容仍需要逐批编写及核查。

验证：37 项后端测试、前端构建；独立数据库的 Edge 浏览器验证课程六单元、单词音标与词性、双语例句、展开词形、词典内容共用及深浅色固定布局。原学习键盘流程亦作回归。
