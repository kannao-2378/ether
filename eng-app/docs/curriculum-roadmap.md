# 基础课程路线与依据

状态：路线草案；仅 want-01 已实现。不是复制教材课程，也不将教材目录作为唯一固定教学顺序。

第一课 want-01：使用当前熟悉的 want to 做纵向样课；并不表示所有零基础学生应跳过 be、代词等基础。提供 I、want、water、drink、learn English 的支持；后续应增加基础诊断和补课入口。

规则依据：British Council A1–A2 “Verbs followed by -ing or infinitive”。want 后连接另一个动词时使用 to + infinitive；不是所有动词都这样使用。
https://learnenglish.britishcouncil.org/free-resources/grammar/a1-a2/verbs-followed-ing-or-infinitive

want-01 六步：结构理解选择、want + 事物、want to 默写、动作短语、完整句子、learn English 换情境。所有作答持久化，错题原地重试，正答推进；回看规则记提示。选择题只作理解检查，不抬高搭配掌握等级。即时课程完成不授予长期掌握；现有复习与准入照常运行。当前课内进度独立保存，尚未将迁移证据自动合并到原复习引擎。
