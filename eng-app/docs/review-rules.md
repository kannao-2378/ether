# 复习规则 v2

- 题数指实际完成并反馈的书写题，刷新、看答案和返回改选不增加题数。
- 忘记：中间完成 2 题；模糊：4 题；认识但有错或提示：4 题；独立认识：8 题。
- 题目不足时优先加入未学内容，再选最接近到期且不是刚做过的项；不提前抽取未来的跨天任务。
- 三次连续独立通过后，至少 24 小时再验证。跨 24 小时独立通过，间隔乘 2.2，最高 180 天。未通过回到当天队列。
- 原始答案不覆盖。返回改选追加反馈事件，按该搭配全部历史重放计算；同一道题不重复增加练习次数。改选从原题完成时的位置重算，已经经过的题数也算在内。
- 已有旧记录保留旧时间安排，下一次反馈或改选时按 v2 重算该搭配。
- 当前仍是明确规则调度，不是墨墨算法或 FSRS。

验证：`python -m unittest discover -s backend -p test_scheduler.py -v`
