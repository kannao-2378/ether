# 项目来龙去脉

## 最初需求

用户英语基础不完整：认识词但不会组织句子，容易逐字翻译，看答案会但脱离提示回忆不出来。希望一个长期记录进度、持续复习、从搭配走向表达的教学系统，而不是静态知识页面或聊天机器人。

最初规划：Windows 本地 Web 应用，React + TypeScript + Vite，Python FastAPI，SQLite。未来可包装桌面端或手机 App。当前没有采用复杂云架构，也没有在线大模型依赖。

## 已发生的重要演变

1. 先用 9 组搭配验证书写、保存、反馈与复习闭环。
2. 借鉴墨墨的操作节奏：直接输入、自动检查、释义页反馈后进入下一项；不是复刻其私有算法。
3. 增加短语、句子和中文情境；已学材料作为依赖，避免用未学单词考迁移。
4. 将词典、课程和今日学习连接到同一组 knowledge ID，避免重复建立互不相认的知识库。
5. 合并并精简导航，形成今日学习、学习计划、我的词典、学习档案、设置五个入口。
6. 引入 py-fsrs 6.3.2（FSRS-6），保留当天题数巩固、教学证据门槛和并发 12 项限制。
7. 扩充课程包：3000 个来源表达、6538 个双语例句、3885 个词汇材料；与已有内容去重后共 13452 项，12 条课程路线、229 个单元。
8. 增加手机适配、Home Screen 网页 App 使用、音频缓存与独立密码登录。
9. 在现有 ether GitHub 仓库增加 eng-app，kan 首页增加英语学习入口；用户在阿里云完成部署。
10. 建立服务器变化检测备份、Windows 每周下载，私人备份保留在本项目“学习数据备份”文件夹。

## 当前边界

“3000 表达”不等于官方审定的 3000 高频搭配教材。课程有来源追踪，但自动主题/句法整理没有全部人工复核。来源与许可见 backend/resources/THIRD_PARTY_NOTICES.md。

固定答案与预登记组合可验证指定练习，但不能覆盖任意自然语言表达。语音来源包括牛津在线单词缓存及离线合成，并非所有内容都有牛津真人录音。

原设想中的高级自由对话、跨文化交流、自动训练个人模型、iOS 原生 App、微信小程序、完整离线同步没有全部实现。不要对外声称已完成。

## 交互偏好

用户希望少文案、少外框、紧凑扁平布局；手机导航五等分，底部操作三等分。标题区两状态高度一致（当前手机 70px），主文字与读音间距为 0，组合上移 5px。反馈选择标记用右上角 √ 和 1px 内描边，不移动文字。改变这些值前应明确需求。
