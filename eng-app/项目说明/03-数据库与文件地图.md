# 数据库与文件地图

## 不是每个功能一个数据库文件

业务上可叫知识库、计划库、掌握库、复习库，物理上主要是同一个 SQLite 文件里的不同表。

| 文件 | 位置 | 用途 |
|---|---|---|
| learning.db | 本地 backend/data；线上 /var/lib/pels | 真实课程、进度、答案、复习与设置 |
| testing.db | 同数据目录 | 隔离测试记录，不代表真实学习；线上不开放测试接口 |
| auth.db | 线上 /var/lib/pels | 登录会话；不含可直接读出的明文密码 |
| 音频 | 数据目录 audio/oxford-us、audio/device-us | MP3、来源元数据与 WAV 缓存 |

PELS_DATA_DIR 决定实际数据目录，不能仅凭当前工作目录猜数据库。SQLite 运行时可能有 -wal/-shm/-journal 辅助文件；运行中不要只复制主文件作可靠备份。

## 核心表关系

大多数表使用 knowledge_id 关联 knowledge.id。关系可能通过代码和唯一约束维护，不保证全部声明了数据库外键。

| 表 | 保存什么 |
|---|---|
| knowledge | 知识 ID、中文题干、英文答案、基础解释、例句 |
| knowledge_details | 词性、音标、音节、结构、词形、延伸等 JSON 详情 |
| learning_courses / course_units / course_items | 课程 → 单元 → 知识项的顺序与归属 |
| content_packages / package_members | 来源课程包、版本、成员关系 |
| knowledge_components | 内容包含哪些成分，如句子包含表达 |
| course_links | 知识项前置父项、阶段、来源 |
| transfer_materials | 做某道迁移题之前需要哪些材料 |
| sentence_combinations | 结构＋材料的组合关系 |
| questions | 已发出的题目及是否提示 |
| spelling_checks | 每次拼写检查原文、结果、时间 |
| answers | 正式完成的答案、反馈、是否提示、复习快照等；question_id 唯一防重复 |
| feedback_events | 返回改选的历史事件，最新反馈参与重算 |
| progress | 单项累计次数、连续独立成功、内部等级、最近和下次时间 |
| memory_states | FSRS Card JSON、上次处理答案与算法名 |
| review_queue | 当天到期题序、跨天 due_at、gap、算法版本 |
| consolidation_slots | 当前最多12项巩固池的持久成员 |
| daily_tasks | 原逐项任务审计；正式额度已由daily_group_tasks计算 |
| daily_extensions | 当天加学额度与幂等请求ID，只当天生效 |
| daily_new_pacing | 当天新内容引入节奏检查点 |
| daily_coverage | 高级表达覆盖基础内容的当天证据 |
| knowledge_assessments | 根据历史计算的证据摘要，供词典/档案使用 |
| rule_readings | 阅读过的规则，不等于掌握 |
| lesson_attempts | 规则课练习记录 |
| context_rounds / context_round_items | 组合情境出题轮次与本轮已出项 |
| composition_evidence | 独立组合使用证据 |
| app_settings | 主题、课程选择、每日上限、语音、快捷键等 |
| test_skips / test_clock | 测试跳过、模拟时间和阶段；不应制造真实掌握证据 |
| sessions（auth.db） | 已哈希的登录 token、CSRF、有效期、凭证指纹 |

未创建最初设想中的全部独立 ORM 实体。当前使用 SQLAlchemy engine + SQL text，不能按“传统 models.py 项目”去找不存在的文件。

## 代码导航

- backend/app.py：启动初始化、迁移、路由、事务与业务编排。
- scheduler.py：题序/到期筛选、FSRS更新、覆盖与12项池。
- assessment.py：长期保持/迁移证据；learning_profile.py 有部分旧内部等级辅助逻辑，不能把旧文字直接当新版词典标签。
- context_engine.py / combinations.py / transfer.py / courses.py：组合题、前置材料、规范化判题、阶段关系。
- content.py / beginner_notes.py / bulk_courses.py：词典详情、初学者讲解、课程包安装。
- learning_stats.py / memory_curve.py：档案与预测曲线。
- private_auth.py：独立登录；oxford_audio.py / device_audio.py：语音。
- frontend/src/main.tsx：页面编排和学习状态；Study.tsx：练习交互。
- Plan、Dictionary、LearningProfile、settings：对应页面；sharedSetting：后端共享设置。
- scripts/：构建课程、模拟测试、导出、发布、下载备份。
- deploy/：Nginx、systemd、配置模板与操作文档。

知识详情字段和实际表列以代码及同目录结构快照为准。JSON 详情使用 payload 扩展，并非全部内容都直接塞进 knowledge 的五列。
