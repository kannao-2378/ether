# 本地运行与测试

本地开发目录：`E:\All file\trae\yingyuxuexi`。

## 启动

Windows PowerShell：

```powershell
Set-Location -LiteralPath 'E:\All file\trae\yingyuxuexi'
.\start.ps1
```

脚本后台启动8000，前台启动5173。重复执行可能端口冲突；关掉Vite窗口不保证后端也停止。先检查端口再启动，不要杀掉所有Python或Node进程。

首次安装：Python3.11+、Node20.19+；创建 .venv，安装 backend/requirements.txt，npm ci --prefix frontend。

本地 localhost 默认无需密码，测试模式使用 testing.db。测试时务必隔离数据库，不用真实学习记录造模拟答案。

## 正式前端构建

```powershell
$env:Path='C:\Program Files\nodejs;'+$env:Path
npm.cmd run build --prefix frontend -- --base=/eng/
```

输出 frontend/dist。theme-init.js 是故意放在首屏之前的阻塞主题初始化脚本，Vite 提示非module不能打包不代表构建失败；需确认该文件仍复制到dist且路径为/eng/。

手机小字号输入框可能触发iOS缩放，真机验证不能省。theme-init.js＋theme.ts 负责首屏和共享主题，修改其他样式时不要又写回固定浅色 meta 或透明导航。

## 回归测试

```powershell
$env:PELS_SKIP_BULK='1'
$env:PELS_DATA_DIR=Join-Path $PWD '.tools\audit-test-import'
.\.venv\Scripts\python.exe -m unittest discover -s backend -p 'test_*.py'
```

环境变量仅用于测试进程；测试后清除再启动正常服务：

```powershell
Remove-Item Env:PELS_SKIP_BULK,Env:PELS_DATA_DIR -ErrorAction SilentlyContinue
```
