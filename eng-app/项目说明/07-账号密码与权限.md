## 英语登录

目前单密码、单学习档案，无注册多用户体系；修改密码不产生新学习档案。PBKDF2-SHA256使用随机盐和600000次迭代；Cookie Secure、HttpOnly、SameSite=Lax、路径/eng/，会话最长14天。token以摘要保存在auth.db，退出可撤销；写请求有Origin/CSRF检查。当前失败限流保存在进程内，服务重启后不保留，不要误称完整安全平台。

创建密码脚本会交互输入两次，至少12位，不回显，默认拒绝覆盖已有配置。忘记密码不能从摘要还原；可以在服务器交互生成新的配置文件，再检查配置中其他路径一致后替换并重启。不要把明文密码写在命令行参数或Git。

推荐更换步骤（服务器，原配置先私密备份；如果临时文件已存在先核查，不能覆盖）：

```bash
sudo cp -p /etc/pels/english.env /etc/pels/english.env.before-password-change
sudo /opt/pels/.venv/bin/python /opt/pels/scripts/create_auth_env.py --output /etc/pels/english-new.env
```

只有明确看到Created提示、两次密码成功后才执行：

```bash
sudo mv /etc/pels/english-new.env /etc/pels/english.env
sudo chmod 600 /etc/pels/english.env
sudo systemctl restart pels-english
```

旧会话凭证指纹改变后失效，用户重新登录。以上只改英语登录，不改SSH。

## 备份专用SSH密钥

私钥：`C:\Users\X\.ssh\english_backup`，公钥同名.pub。私钥不在项目里，不上传Git、不发聊天。公钥安装在服务器admin的 /home/admin/.ssh/authorized_keys，前缀restrict；已验证免密可列出备份。

restrict禁止PTY及转发等，不等于只读备份沙箱：仍是admin账号的执行权限。目前未建立只能下载备份的专用强制命令账号；如果未来扩展给别人使用，需另做最小权限账户。脚本使用BatchMode/IdentitiesOnly和严格主机指纹检查，服务器重装导致指纹变化应核验后再更新known_hosts，不能直接禁用校验。

不要读取另一个项目的.gh-config登录凭证来绕过认证。此前该操作被自动审批拒绝，后来通过正常Git登录成功推送。后续仍走正式授权，不在文档复制任何token。
