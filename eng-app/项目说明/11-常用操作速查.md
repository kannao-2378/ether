# 常用操作速查

## 我改了本地页面，网站为什么没变化

本地保存 → 本地验证 → 构建/eng/ → 同步到发布仓库eng-app → 提交推送GitHub → 用户在阿里云git pull → 复制到静态运行目录 → 浏览器刷新。任何一步跳过都可能仍是旧代码。网站源码和本地开发不是自动同步。

## 我换手机，学习记录会不会没了

同样访问kannao.top/eng/并用英语密码登录，是同一份线上数据。localhost不会跟线上自动合并。清浏览器缓存通常只影响登录/首屏偏好，不应删服务器学习记录。

## 我更新Git会不会清记录

代码更新命令不复制/var/lib/pels，也不删除.env，所以不应主动重置进度；但程序可能执行数据库迁移，仍必须先备份。不要把“更新不覆盖数据”误解为软件永远不可能有bug。

## 忘了是哪种密码

进网页学习：英语密码。电脑SSH：root服务器密码或admin专用密钥。管理云服务器：阿里云账号。推代码：GitHub授权。这四种不是一个东西。

## 如何暂停电脑自动下载

PowerShell：

```powershell
Disable-ScheduledTask -TaskName 'PELS-EnglishBackup'
```

恢复：

```powershell
Enable-ScheduledTask -TaskName 'PELS-EnglishBackup'
```

暂停下载不删除已有ZIP，也不停止阿里云每天的数据库快照。不要因此删除服务器数据库。

## 如何手动下载

```powershell
& 'E:\All file\trae\yingyuxuexi\学习数据备份\download-backups.ps1'
```

若PowerShell执行策略阻止脚本，仅本次进程执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'E:\All file\trae\yingyuxuexi\学习数据备份\download-backups.ps1'
```

日志在同目录download.log。私钥仍应在用户.ssh目录，不在备份目录。
