## 一、课程怎么组织

主线按表达能力递进，主题提供场景，规则解释组织方式。不是把所有单词学完再学搭配，也不是先背完语法再说话。主线共8阶段、32单元、128个课题位置；每单元4个课题，课题里可有多个共享知识项。128个课题不等于128组，也不是128天。

每课题只设一个主要表达目标。单元内顺序是默认路径，不强制已经具备证据的学习者重复基础；不同分支按具体先修连接，不要求整阶段全部稳固后才能前进。迁移与长期稳固分开记录。

本次调整：从第一阶段引入简单听辨、提问和否定；补齐名词、冠词、代词、动词两类句子等基础；把复杂句和领域表达放到相应先修后；听说读写、回忆和迁移贯穿所有阶段。

参考欧洲委员会的能力目标与语言活动框架、British Council基础语法范围，下面具体顺序为本项目设计，不是官方教材目录、CEFR认证课程或达到某等级的保证。

## 二、通用英语主线目录

### 第一阶段：能听懂并组织最简单的表达

完成目标：能介绍自己、说出简单动作、询问和否定基本信息；能用已学材料做简短新组合。

#### U01 我、你和身边的人与物
- U01.1 人是谁：I、you、he、she、we、they；结合人物与声音辨认，不先背术语。
- U01.2 说明身份或状态：I am、you are、he/she is。
- U01.3 指认眼前事物：this/that、a/an；This is a book.
- U01.4 简单确认与否定：Is this…?、Yes/No、is not；不预设所有问句都用do。

#### U02 我做什么：动作与对象
- U02.1 喝与吃：drink water、eat rice；先教必要材料。
- U02.2 阅读与学习：read books、learn English。
- U02.3 回家与去学校：go home、go to school；比较有无to。
- U02.4 组织完整表达：I + 已学动作；换动作、对象做首次迁移。

#### U03 我的东西和动作涉及的人
- U03.1 表达拥有：I have…；基本数量与具体物品配合。
- U03.2 谁的东西：my、your、his、her；my book。
- U03.3 动作涉及谁：me、you、him、her、us、them；先学help等必要动作。
- U03.4 区分“我、我的、对我”：I / my / me；放进完整小情境。

#### U04 说不、问问题、听懂回答
- U04.1 否定动作：I don't…；对照I am not…。
- U04.2 询问动作：Do you…?；Yes, I do. / No, I don't.
- U04.3 询问是什么、在哪里：What is…?、Where is…?；地点答案先用少量已教词块。
- U04.4 完成初次交流：介绍、提问、回应；听懂慢速短问句后作答。

### 第二阶段：把人、事物、地点和日常说清楚

完成目标：能描述具体事物、数量、位置和基本日常，不只会一条固定句。

#### U05 数量与东西的说法
- U05.1 数字与数量：one/two…、常见复数及发音。
- U05.2 一个、一些和特定的东西：a/an、some、the；先讲具体语境，不一次罗列全部冠词规则。
- U05.3 水与一杯水：water、a glass of water；可数与不可数用实物解释。
- U05.4 询问多少：How many / How much；结合已学数量表达。

#### U06 描述外观、状态和归属
- U06.1 给东西加描述：a big room、a useful book。
- U06.2 描述人或物的状态：be + tired / busy / useful。
- U06.3 补充程度、并列和转折：very、and、but。
- U06.4 用几条短句描述同一个人或物；避免堆新形容词。

#### U07 地点与空间关系
- U07.1 在哪里：in、on、under；配图和已学物品。
- U07.2 附近与前后：next to、in front of、behind。
- U07.3 某处有什么：There is / There are。
- U07.4 位置与移动的区别：at school / go to school；go home复现。

#### U08 时间与日常规律
- U08.1 时间、日期与时段：at seven、in the morning、at night。
- U08.2 每天、多经常：every day、usually、sometimes；结合日常动作。
- U08.3 说他/她的日常：he works、she reads；第三人称变化及does/doesn't。
- U08.4 询问什么时候、多经常：When / What time / How often；描述自己和另一人的日常。

### 第三阶段：表达需要、喜好、计划和互动

完成目标：能把常见动词搭配用于新的已知动作，理解英语中动作如何衔接。

#### U09 我想要什么、想做什么
- U09.1 想要东西：want + 东西。
- U09.2 想做动作：want to + 动作；换已知动作迁移。
- U09.3 需要东西或做事：need + 东西 / need to + 动作。
- U09.4 询问和否定需求：Do you want to…? / I don't need to…。

#### U10 喜欢、享受和偏好
- U10.1 喜欢东西：like + 东西。
- U10.2 喜欢做事：like doing / like to do；先教常见用法，不宣称永远可互换。
- U10.3 享受做事：enjoy doing；阅读、学习等已知动作的形式变化。
- U10.4 表达并比较喜好：love、don't like、prefer A to B；迁移到新场景。

#### U11 打算、决定与行动过程
- U11.1 计划和希望：plan to、hope to；围绕一个可执行目标。
- U11.2 作出决定：decide to；用自然且符合时态先修的情境。
- U11.3 尝试与学习：try to、learn to；说明不同动作衔接的含义。
- U11.4 练习、继续与完成：practice doing、keep doing、finish doing；按表达功能拆练。

#### U12 听、看、等待与交谈
- U12.1 听与看：listen to、look at；同组材料复用。
- U12.2 等待与寻找：wait for、look for。
- U12.3 跟人交谈、请求东西：talk to、ask for。
- U12.4 解释搭配的边界：look at / look after；不能见到同一核心词就当相同用法。

### 第四阶段：应对生活中的请求、选择与安排

完成目标：能表达能力、提出请求、做选择并完成短交流。

#### U13 能力、许可和义务
- U13.1 能不能做到：can / can't + 动作。
- U13.2 请求或给予许可：Can I…? / You can…。
- U13.3 应该与必须：should、must、have to；说明语气和来源。
- U13.4 不必与禁止：don't have to / mustn't；放在同场景比较。

#### U14 请求、建议与礼貌
- U14.1 简单指令：Please… / Don't…；先学请求所需动作。
- U14.2 礼貌求助：Can/Could you…?；could此处不按过去时机械解释。
- U14.3 礼貌表达需求：I'd like… / I'd like to…。
- U14.4 提议并回应：Let's… / How about…?；接受、拒绝和简短理由。

#### U15 比较、程度与选择
- U15.1 比较两个事物：bigger、better、more useful。
- U15.2 从多个选一个：the best、the most useful。
- U15.3 太多、太少和足够：too、enough、many/much、a little/a few。
- U15.4 表达选择理由：比较价格、便利和偏好；复用已教词汇。

#### U16 日常任务中的短交流
- U16.1 点餐与购物：需求、数量、价格、确认。
- U16.2 问路与出行：位置、方向、交通；补少量必要材料。
- U16.3 约定与安排：时间、地点、接受与改约。
- U16.4 身体与生活问题：状态、求助和一般建议；不把练习当医疗指导。

### 第五阶段：说清现在、过去和未来

完成目标：不只背时间词，能根据事件状态选择表达并讲述简单经历。

#### U17 正在发生与平时习惯
- U17.1 正在做什么：am/is/are doing。
- U17.2 正在做什么吗：疑问、否定及回答。
- U17.3 平时做与现在做：I read / I'm reading。
- U17.4 描述眼前场景：人物、动作、位置；不机械给所有动词加ing。

#### U18 已经发生的事情
- U18.1 过去的身份、状态和位置：was / were。
- U18.2 做过的动作：规则过去式与常用不规则形式，分批引入。
- U18.3 过去的否定与提问：didn't / Did…?；后接基本动词形式。
- U18.4 过去的习惯与现在对照：used to；与一次性过去事件区分。

#### U19 按顺序讲述一件事
- U19.1 先后顺序：first、then、after that、finally。
- U19.2 过去某时正在发生：was/were doing。
- U19.3 一件事发生时另一件事怎样：when / while，连接具体事件。
- U19.4 讲述一天或一次小经历：背景、过程、结果。

#### U20 未来、意图与安排
- U20.1 已有意图：be going to + 动作。
- U20.2 临时决定、承诺与预测：will；不把will等同所有未来。
- U20.3 已安排好的活动：现在进行形式表达安排，配清楚时间情境。
- U20.4 比较计划与变化：plan to / going to / will；根据语境作答。

### 第六阶段：解释经历、原因和可能性

完成目标：能说明经历、持续时间、原因、目的和现实条件。

#### U21 经历与已经完成的事情
- U21.1 曾经做过：have/has + 过去分词；分批复用词形。
- U21.2 已经、还没和刚刚：already、yet、just。
- U21.3 有没有经历过：ever / never；提问与回答。
- U21.4 经历与具体过去时间：have done / did；用同一事件作对照。

#### U22 从过去持续到现在
- U22.1 持续多久：for + 时长。
- U22.2 从何时开始：since + 起点。
- U22.3 问持续时间：How long…?；对照ago，不混用时间逻辑。
- U22.4 强调持续活动：have been doing；与状态和完成结果比较。

#### U23 原因、目的、结果和让步
- U23.1 为什么：because + 一句话 / because of + 名词表达。
- U23.2 为了什么：to / in order to + 动作。
- U23.3 所以怎样：so、结果说明；不把所有so结构混为一种。
- U23.4 虽然如此：although、however；连接已能独立写出的短句。

#### U24 条件、可能与不确定
- U24.1 如果发生会怎样：if + 现实条件；主句结果。
- U24.2 可能但不确定：may / might / could；结合语气与情境。
- U24.3 除非、只要和限制：unless、as long as；避免只背中文替换表。
- U24.4 根据信息做判断：可能原因、条件与下一步安排。

### 第七阶段：把信息连接成长句

完成目标：长句由已理解的信息组合而来，能解释、转述和补充说明。

#### U25 把想法放进一句话
- U25.1 我认为、知道：I think/know that…。
- U25.2 我不确定是否：whether / if引入不确定内容。
- U25.3 我不知道哪里、怎么：where / how / what引导内容，注意陈述语序。
- U25.4 我想知道：I wonder…；区分直接提问与句内问题。

#### U26 说明是哪一个人或东西
- U26.1 说明是哪一个人：who / that。
- U26.2 说明是哪一个东西：which / that。
- U26.3 说明地点或归属：where / whose。
- U26.4 必要限定与补充说明：语义、逗号和信息分组；书写提示与内容评分分开。

#### U27 把重点放在事情或结果上
- U27.1 谁做与什么被做：主动和被动的区别。
- U27.2 现在或过去被怎样处理：is made / was designed。
- U27.3 能被、需要被怎样处理：can be / should be。
- U27.4 描述产品、流程与结果：自然选择主被动，不机械转换所有句子。

#### U28 转述和交代更早的事情
- U28.1 到过去某时已经发生：had done；用事件线解释。
- U28.2 转述陈述：said / told；人称、时间和语境变化。
- U28.3 转述提问：asked if / asked what；句内语序。
- U28.4 整理多方信息：谁说了什么、何时发生、哪些仍待确认。

### 第八阶段：表达观点、反思并持续交流

完成目标：能连贯表达、回应和修正，不把写出一条复杂句当最终能力。

#### U29 观点、理由与证据
- U29.1 同意与保留意见：agree / disagree / partly agree。
- U29.2 提出理由与例子：claim、reason、example的实际组织。
- U29.3 区分事实与判断：It seems… / The evidence suggests…；相应词汇先教。
- U29.4 比较两种观点：优势、限制与有条件的结论。

#### U30 回想、假设与自我追问
- U30.1 回忆与意识到：remember、recall、realize；不要强行同义替换。
- U30.2 如果情况不同：与现在不同的假设，if + 过去形式 / would。
- U30.3 对过去的反思：过去未实现条件与可能结果；作为进阶分支，不阻塞基础交流。
- U30.4 动机与价值追问：Why do I…? / What matters to me…?；用理由和经历支持。

#### U31 从一句话到一段表达
- U31.1 一段话围绕一个重点：观点、展开、结尾。
- U31.2 指代与衔接：this、it、they及连接词，避免指代不清。
- U31.3 语气与受众：日常聊天、礼貌消息、较正式说明。
- U31.4 解释一个选择或方案：短消息、短段落与口头复述。

#### U32 真实互动与表达修复
- U32.1 没听懂时：请求重复、放慢、解释。
- U32.2 不会某个词时：用已知词解释、举例、换说法。
- U32.3 回应、追问与协商：接住对方的话，确认理解。
- U32.4 综合任务：说明问题、讨论方案、作出选择并回应异议。

## 三、贯穿每一课的训练线

1. 听与读：听清目标表达，辨认词音和必要音节；读懂短材料。音标帮助查读，不作为开始表达前必须背完的门槛。
2. 理解：用白话说明用在什么情境、为什么这样组织。语法名词是补充，不用术语替代解释。
3. 无提示回忆：看中文或情境写英文，记录错误、提示和反馈；可按现有逐词横线输入。听音辨认与拼写成绩分开。
4. 新组合：用已学材料换对象、动作或场景；先不给完整英文。不是每个名词都要孤立配五个迁移句。
5. 脱离逐字翻译：逐步加入图景、英文短问答、真实意图与短对话；中文起步，不让中文翻译成为唯一通道。
6. 输出与互动：从短回应到短段落，安排跟读、朗读、口头表达与听后回答。现有播放按钮不等于已具备口语评测，相关活动须另开发。
7. 延迟复习：已有记忆算法安排复习，教学目标及先修由课程管理。FSRS不负责判断一句话自然不自然，也不决定整套课程教学顺序。

听说读写都纳入目录，但后续必须分别标明“已实现/手动练习/待开发”，不能用拼写正确冒充听懂或能说。

## 四、领域分支目录

分支不是通用主线结束后才能看。具体课有足够先修就可选，例如早期可练描述设计外观，复杂政策论证需要后面的能力。专业知识不是通用英语能力的自动产物。

| 分支 | 由浅入深的单元目录 |
|---|---|
| D01 自我、情绪与思考 | 日常感受 → 习惯与动机 → 回忆与变化 → 身份、选择与自我追问 |
| D02 设计、品牌与创作 | 外观与功能 → 用户与使用情境 → 品牌定位与理念 → 方案说明、评审与反馈 |
| D03 金钱、商业与金融 | 收入、支出与价格 → 成本与商业模式 → 风险、收益与市场 → 比较观点和解释经济现象 |
| D04 哲学、价值与理念 | 喜好与价值选择 → 意义、自由与责任 → 定义与观点 → 理由、反例与论证 |
| D05 社会、政治与公共议题 | 日常公共生活 → 制度、权利与政策 → 不同立场与影响 → 证据、权衡与讨论 |
| D06 工作、学习与沟通 | 任务与时间安排 → 协作与请求 → 问题与解决方案 → 协商、复盘与反馈 |
| D07 生活与跨文化交流 | 饮食、住行与健康 → 人际关系 → 礼貌与文化差异 → 误解澄清与持续对话 |

各分支现阶段仅列单元范围，不将28个分支单元算入128项主线，也不预造已完成数量。优先补足通用基础，再按使用频率开发选定分支。

## 五、每课交付规格

每课题必须有：稳定ID、一个主要表达目标、对应单元、明确先修、必要知识项、白话讲解、示范、独立练习、迁移/语境验证、复习关联、来源与编辑审核状态。

知识项引用词典中的具体词义、搭配、短语或句子；保留原文、中文、词性、必要读音、用法、例句等已有字段。同一知识项跨课复用，不复制熟悉程度。例句原文、译文和来源许可分别保留，不能把来自社区语料的句子标成官方教材审核。

迁移按目标设计：句型或高复用搭配优先准备3～5个有差异的候选情境，数量是备课初值；简单名词用少量语境辨认和独立运用，不能机械要求全课统一五题。示范句不计首次新迁移。有限题库耗尽后只剩复习，必须如实显示缺口，不能保证无限新情境。

初期允许优先补必要材料，材料不足时小批准备，不能自动塞入几十项。必须保留可先做的其他课；某个词长期不会只影响依赖它的任务，不堵住全部路线。替代材料仍需预先审校，不能任意拼接。

句子输入应接受预先审核的合理答案变体。现有固定答案检查不能保证任意正确表达都能识别；开放观点/段落任务必须另外设计批改方式，不能直接套定长自动判断。拼写、记忆反馈、迁移、听力、口语和书写规范分别计证据。

## 六、如何连接现有计划、分组和历史

- 目录：阶段 → 单元 → 课题 → 学习目标 → 共享知识项/练习。课题是教学组织，组是既有额度和任务身份；课题可能引用多个组，同一组也可被多课复用。
- listen、listen to、listen to music若围绕同一个目标可作为一组的材料和扩展；look at与look after表达含义不同，不能因为同根强行并组。新增必要材料如果是独立新组，仍按既有规则占额，不因隐藏在课程里就免费。
- 每日额度在目标组层去重；不能把128课等同128个额度，也不能为了完成50组强行拆词凑数。继续沿用12个待巩固活动组等已实现限制，本稿不修改参数。
- 今日学习从所选课程已发布、先修满足的目标中安排，穿插到期复习、巩固、专项和迁移；不是把目录第一行至第五十行机械塞入。
- “当前可继续学习”基于必要基础的实际证据；不要求长期稳固。“迁移已验证”和“长期记得住”分别呈现；误用、遗忘后按对应证据补练。
- 上线课程版本必须保持旧知识ID和原始答案记录；做旧50目标与新课题的映射，不能直接清库、重置课程或把旧熟句改成从未见过的迁移题。

## 七、目录核对与落地顺序

本稿已做设计层检查：数量是8×4×4=128；提问、否定、发音和迁移从早期出现；名词/代词/冠词、be/动作句先于复杂长句；一般过去先于过去叙事，过去分词经验先于被动，条件基础先于反事实；领域分支有通用先修接口。

这不是教学效果认证，也不是运行测试。具体依赖还须在编课清单中逐条标注，目录编号本身不代表所有先修已满足。

下一步按U01–U32形成完整课目清单：逐课盘点已有内容、缺少内容、依赖、可用原句与题型。先把全主线的范围和缺口一次登记清楚，再集中准备第一阶段内容，避免临时补一句就宣称完成一课。后续分阶段实现，第一阶段形成完整可运行小闭环后再扩大；其余内容状态明确保留为设计或待编写。

正式发布前检查：目标与练习匹配、词义和自然度、先修无环、无提示答案不泄漏、共享记录不重复占额、合理答案变体、未学材料不被假定掌握、复习和迁移独立记录。只在独立数据库验证；不改真实记录或默认启用新路线。
