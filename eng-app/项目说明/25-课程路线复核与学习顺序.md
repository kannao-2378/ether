# 课程路线复核与学习顺序

设计稿v4，2026-11-04。最新解释以本文及机器清单v4为准。22–24号文件是此前版本快照，旧编号保留。本轮没有修改任何真实学习记录、运行排题、FSRS参数、组额度、服务或线上内容。

## 结论与修正

原骨架可以继续使用，但“按U01到U32学完一章才进下一章”的读法不合适。此前所谓顺序检查主要检查目录和导航引用，并没有等于完整的逐目标先修审查。本轮把分类地图与推荐学习路线分开，完整安置148个课题及729条实际学习目标，并对40个关键能力节点登记设计依赖。

725条旧目标里有6条是软件或编辑要求，本次保留原ID与原文作为质量约束，不再计入学生学习量。另补1个对象状态课题、5条基础交流/数量/活动表达目标，共10条新增目标。因此现在是725−6+10=729条，而非靠增加条目制造完整性。

## 发现的具体顺序问题

| 问题 | 修正 |
|---|---|
| want to放在数量、日期、地点全单元之后，容易过慢 | 简单动作与需求基础具备就可引入；wants作为后续扩展 |
| be doing首次出现被放到原第五阶段 | 核心用法移到新路线R02，依be与当前动作，不等到全部日常交流结束 |
| Who called出现在较早的问句补充，但未注明过去式先修 | 对应目标移到R04，关键图明确依过去动作与did问题 |
| U01的it课题同时要求读钟点，实际又依U08 | 天气词块可先用，钟点目标等数字、时间能力具备；不锁整个U01 |
| decide to用一般现在时凑初心例句可能生硬 | 默认在过去动作具备后练自然的过去决定，不先展示未教时态让用户抄 |
| 求助、礼貌表达、简单观点和短消息太晚 | 基本词块与简单任务提前，后期仍保留深化训练 |
| remember两种结构和请求重复在前后课重复列出 | 明确复用相同用法证据，后课深化，不伪造新的首次掌握 |
| 词根词族只在后期系统介绍 | 早期随具体词提供已核对辅助，后期系统梳理，不先背完词根 |

这些是项目教学设计的修正，不是官方唯一课程顺序。阶段不是天数，也不是需要一次背完的一批材料。

## 推荐实际路线

| 窗口 | 主要任务 | 说明 |
|---|---|---|
| R01 | 基本动作、简单句、需求、初步问答和求助 | 先少量固定词块；材料足够就可做第一道新组合 |
| R02 | 描述、数量位置时间、喜好与正在发生的事 | 加第三人称、doing和新对象；不把所有时间词当成前置 |
| R03 | 日常任务、请求、比较、计划和简短理由 | 同时可选择具备基础的设计、工作等主题词汇 |
| R04 | 过去经历、变化、未来安排与相关辨析 | 自然引入decided、过去式问句和叙事 |
| R05 | 经历持续、原因、条件和不确定 | 先比较简单过去与完成，再延展持续与推断 |
| R06 | 长句、限定、被动重点、转述 | 由已有短信息组合，不先要求写复杂长句 |
| R07 | 观点、证据、假设、反思与段落 | 简单观点早已可用，这里深化；复杂反事实可暂缓 |
| R08 | 综合互动、概括、解释与持续使用 | 不是到这里才第一次交流；领域学习继续循环 |

每课题有一个主要教学窗口，但早期可用的具体目标另有引入窗口。比如U31.1主要在R07系统练段落，其最早的短消息目标在R03，不能等到R07才放行。窗口内下列课题是覆盖清单，不是强制按列表次序逐项学完。默认只引入当前目标最必要的一部分；具体目标可单独前移或后移。机器路线中已登记关键例外，不允许未来实现直接把整个课题当一把解锁锁头。

## 补充的具体内容

U02.6补上“动作使人或东西处于某种状态”：对照I give you a book与I keep the door open，不将动作后的所有内容都叫对象。先用白话讲“给谁什么”和“让东西保持怎样”，语法名称放辅助说明。不要把这项扩展强塞进刚学drink water的入门题。

另在原课题中补入：问候/姓名/拼写姓名、具备数字字母基础后的模拟联系方式、a lot of/lots of、Reading is fun这类以活动为话题的表达、It is important to do这类评价事情的表达。后两项有明确的be、doing或to动作基础后再练。

## 关键起步路径的具体例子

1. 教I及当前必要材料，drink、water与drink water可按实际情况作为本目标材料展开。
2. 能独立回忆当前词块后，教I drink water的组织方式，起初不要求复杂句。
3. 区分want water与want to drink water，说明要东西和想做动作；示范句只算教学及熟句。
4. 确认learn English等替换动作材料自身已会。材料教学不得预告之后的完整目标句。
5. 穿插已有练习后，只给新中文情境尝试表达。本文用于说明的英文不应被软件直接作为迁移预习内容。
6. 需要问句或否定时，先补do/don't等对应基础，再练Do you want to…?等表达；不让整套问句基础阻塞此前已经可练的肯定表达。
7. 已有be和当前doing形式后，开始I am drinking water及正在发生的问答；不等待过去时。
8. 人物和第三人称变化具备后，才练He wants to…；不会wants不应反锁I want to…。
9. 定期加入听懂短问句、脱稿短回应和简单阅读；拼写证据不替代这些能力。
10. 后续按真实间隔复习；新情境是否能用与隔天是否仍记得分别保存。只存在一张熟句时，不能把反复答它叫新迁移。

这是设计路线，具体知识ID、练习题和先修证据仍待教材映射；本轮未在运行系统中执行这十步。

## 领域路线与技能路线

领域分支不是通用课结束后的统一解锁包。例如能描述形状、用途并说明简单理由，就可进入设计描述；能谈价格和数量，可进入生活预算；复杂品牌论证、金融推断或哲学反思再要求对应信息连接和论证能力。专业词汇与具体知识按课补，不能因为通用语法学过就假定已懂。

听力、口头表达、阅读、书写和发音都按当前内容渐进。不会某项口语活动不应让已具备书写能力的所有路线全部冻结；但也不能在学习档案里替它打“已会”。先定义本任务测什么，再决定音频、词长、中文提示是否属于支持条件。

识别语法术语不作为起步条件。先看实例和意义，逐步说明“谁、做什么、对什么、怎样、何时何地”；术语帮助归纳，不能代替用法，也不能把英语只教成一种固定顺序公式。

## 知识分类、教学路线与每天安排

- U编号用于知识分类与交接，R编号用于主要教学窗口；二者不是两套不同教材。
- 学习计划选择路线和额度；每日执行只从已发布且所需条件满足的目标中取任务，穿插复习、巩固与迁移。
- 先修检查针对当前用法/任务，不能要求先完成整章、整阶段或全部长期稳固。
- 反复不会的材料只影响依赖它的任务，不反复强塞同一题或假装它会了；可以做其他材料足够且审校通过的任务。
- 额度与活动池仍沿用既有规则，目录调整不新增隐藏名额，也不强行每天凑满50组。

## 本轮设计校验结果与边界

已校验148课题恰好进入一个推荐窗口，729目标全部有推荐窗口且编号唯一，关键例外引用有效，40个能力节点依赖引用有效且无环，关键能力没有出现前置能力比目标更晚的窗口冲突。主要教学窗口和最早目标窗口分开保存，不能前后混用。设计断言确认：I want to不依赖wants，正在做不依赖过去式，Who called的对照练习依赖过去式/did，换动作需要相应材料准备路径，钟点依赖时间能力；一个替换材料不会不锁住全部其他能力路线。

这只是设计文件和关键图的一致性检查，不是729个目标的完整先修图，不是实际题目验证，也不是教学效果证明。只登记推荐窗口的目标仍不能直接发布。完整词义/材料映射、3000项覆盖、逐题审校、合理答案与技能任务，仍须在编课阶段完成。
