# 页面查询性能优化

2026-11-06，已发布阿里云。下表是扩容前本机测量；扩展至2718路线目标后的最终本地测量为词典0.357秒、档案0.298秒、计划1.04秒，线上运行代码8eb5576。

- 词典先取当前页的 ID，再加载30条详情；无筛选翻页不再关联全库详情。
- 知识类型建立 JSON 表达式索引，词典与档案分类统计共用索引；无详情条目仍归入搭配。
- 档案只遍历已经引入或有练习的条目；全库数量用 SQL 聚合，不逐条计算未学条目的掌握证据。
- 计划页使用概览查询，不再构建页面不用的完整历史和薄弱清单；档案的薄弱项不受影响。
- 页码改为数字输入，回车或失焦跳页，避免顶部和底部分别生成几千个下拉选项。
