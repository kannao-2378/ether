# 自定课程 JSON 与独立复习队列

更新时间：2026-11-08。本功能从“我的词典”页面导入；“今日学习”和“学习计划”使用新队列。课程和状态保存在运行数据目录的学习数据库中；没有修改旧课程行、answers、feedback_events、progress、memory_states 或 review_queue。

## JSON 格式

顶层字段为 `title` 和 `groups`。groups 必须恰好30组并保持用户提供顺序。每组包含：至少一个 vocabulary 词条、一个 target 目标、恰好2个 required_sentences、恰好10个 transfer_cases。整份校验通过后才在单一事务写入；任一错误都会拒绝整份数据，并尽量给出组号/字段。

每个单词需有 `en`、`zh`、`part_of_speech`、`ipa_us`、`ipa_uk`、`syllables`、`stress`、`root_affixes`、`word_forms`、`collocations`、`examples`、`mnemonic`、`spelling`、`needs_review`、`accepted_answers_en`、`vocabulary_used`。例句是 `{ "en": "...", "zh": "..." }` 数组。无适用内容可使用 null 或空数组；needs_review 必须为布尔值，不确定的内容应设 true。词汇本身的 `vocabulary_used` 包含该词英文。

target 有 `type`（rule/collocation/grammar）、`en`、`zh`、`accepted_answers_en`、`vocabulary_used`、`needs_review`。每个必背句和迁移案例有中文 `prompt_zh`、非空 `accepted_answers_en` 英文答案数组、`vocabulary_used` 数组和布尔 `needs_review`；词汇引用必须是同组单词的英文。校验器位于 backend/user_courses.py。

在“我的词典”可粘贴 JSON 或选择 UTF-8 JSON 文件。导入成功后可展开查看原课程 JSON，并进入每日学习。答题比对不区分大小写、折叠多余空格；不放宽拼写或词形。查看答案后可调用现有应用语音播放能力。

导入器也接受 `backend/resources/foundation_30_groups_course.json` 使用的生成器格式：将 `course_title`、词汇、目标和 `sentences_to_memorize` 映射到上述字段；目标答案取 `correct_example_en`。来源 JSON 的原字段保留在导入内容中。`vocabulary_used` 仅保留同组词汇表里的词；来源题目缺少 `needs_review` 时设为 true，提示需要人工复核。

## 状态与排程

`user_course_*` 和 `user_learning_*` 表只保存自定课程、显式自评与独立排程；不映射到旧知识 ID、旧答案/反馈、FSRS 卡或旧队列。每天依用户组序和组内“单词→重点→必背句→迁移”排列全部当前待学内容；先到期内容，再前日未完成，后新内容。完成后按自评间隔暂缓。选择只由用户点击，不推断掌握。

单词自评为模糊/记住/熟悉，其他题为模糊/记住/迁移。首次记住后同一项目会在2–4个其他答题后重现；当天第二次选择记住后，从2天开始复习。记住间隔为2、5、10、30、90、120天，后续每120天。熟悉/迁移间隔为10、30、60、90、120天，后续每120天。模糊项同日隔2–4个其他答题重现；日内未完成则次日接续。日期按 Asia/Shanghai 日历日计算。旧算法仍为兼容代码，但自定课程不调用旧 `/api/next`/FSRS。

“今日学习”和“学习计划”当前均使用新队列；导入入口位于“我的词典”。答案展示由用户主动点击，发音沿用应用语音播放机制。词典查词只保存资料，不再创建旧专项组。旧学习档案页用于查看保留的历史记录；旧数据库与算法代码保留作兼容，但前端学习入口不再调用旧 `/api/next`、学习组、迁移组或 FSRS 队列。新表包含于 SQLite 一致性备份及 `/api/export`。课程原始 JSON 是用户内容，不应把数据库、导出、私人备份、密码或 token 提交到 Git。旧学习记录没有自动迁移。
